❓ Notice d'utilisation

Cette application permet de créer un compte rendu de visite sécurité avec photos annotées, directement depuis votre téléphone ou ordinateur, sans connexion à un serveur.

Le bouton 📋 Aide-mémoire, à côté de celui de la notice, ouvre la liste des points à contrôler pendant la visite (voir § 10). Le bouton 🌐 Enregistrement sur l’intranet règle l’enregistrement des fichiers Excel sur le réseau de l’entreprise (voir § 11).

Un résumé visuel apparaît en haut de la page dès qu'une photo est ajoutée, avec le nombre de points "à corriger", "corrigés" et "bonnes pratiques".

1. Informations générales

  • Renseignez votre nom (et éventuellement un second nom si vous êtes deux), la date et l'heure de la visite.
  • Ajoutez un commentaire général qui résume la visite (facultatif). Le bouton 🎙️ permet de dicter le texte à voix haute au lieu de le taper.

2. Ajouter une photo

  • 📷 Ouvrir l'appareil photo : prend une photo directement avec la caméra (nécessite un site en HTTPS).
  • 🖼️ Choisir une photo de la galerie : importe une photo déjà présente sur l'appareil.

3. Annoter la photo

  • Utilisez les boutons 🔍− / 100% / 🔍+ pour zoomer sur la photo.
  • ✚ Croix rouge et ◯ Cercle rouge : dessinez sur la photo pour repérer un point précis (glissez avec le doigt ou la souris).
  • ↶ Annuler : supprime la dernière annotation.
  • 🗑 Effacer tout : supprime toutes les annotations de la photo en cours.

4. Qualifier la photo

  • Ajoutez un commentaire décrivant ce qui est observé sur la photo (bouton 🎙️ pour dicter à voix haute).
  • Choisissez une action :
    • ⚠️ A corriger — un point nécessitant une correction.
    • ✅ Corrigé — un point déjà réglé.
    • 👍 Bonne pratique — un point positif à valoriser.
  • Pour un point "A corriger", précisez le niveau de gravité : 🟡 Mineur 🟠 Majeur 🔴 Urgent.
  • Vous pouvez aussi ajouter une photo de comparaison (avant/après, autre angle) avant de valider : 📷 Prendre une 2e photo ou 🖼️ Choisir une 2e photo, puis 🗑 Retirer si besoin de l'enlever. Elle apparaîtra à côté de la photo principale dans la liste et dans les exports.
  • Cliquez sur ✅ Ajouter cette photo au rapport pour l'enregistrer dans la liste.

5. Gérer les photos du rapport

  • ✏️ Éditer : rouvre la photo dans l'éditeur pour modifier les annotations, le commentaire ou l'action.
  • Supprimer : retire la photo du rapport.

6. Exporter le rapport

  • 📊 Excel : génère un fichier .xlsx avec toutes les photos, commentaires et actions. Il peut aussi être enregistré automatiquement sur l’intranet (voir § 11).
  • 📄 PDF stylisé : génère un fichier .pdf mis en forme, prêt à être imprimé ou partagé.

7. Sauvegarde automatique

Le rapport est sauvegardé automatiquement sur l'appareil au fur et à mesure de la saisie. Vous pouvez fermer la page et reprendre plus tard, tant que vous utilisez le même téléphone, le même navigateur et le même site.

🆕 Nouveau rapport efface définitivement la sauvegarde en cours et repart d'un rapport vide.

8. Sauvegarde partagée Supabase

Les deux exports Excel placent la date de visite avant le numéro, sous forme de date Excel au format jj/mm/aaaa.

Lorsque vous cliquez sur 📊 Excel, la visite est également enregistrée dans la base Supabase partagée. Aucune connexion ni compte utilisateur n'est demandé.

Si une visite existe déjà pour la même date, la nouvelle visite est tout de même enregistrée et le champ Doublon est mis à OUI.

Le bouton 🗄️ Excel base complète télécharge toutes les visites enregistrées dans Supabase, avec la date en première colonne, le numéro, le champ Doublon, les commentaires, actions, gravités et les photos principales et de comparaison intégrées. Les liens restent disponibles. Une connexion Internet est nécessaire et un avertissement signale les photos indisponibles.

Les photos sont envoyées dans le compartiment Supabase Storage visites ; seuls leurs liens sont conservés dans la base de données.

9. Mode hors ligne et mise à jour

Pour démarrer l’application même sans connexion, ouvrez-la une première fois en ligne depuis son adresse HTTPS. Le service worker enregistre alors la page, les polices et les modules nécessaires dans la mémoire du navigateur.

Ensuite, appuyez sur le bouton 📲 Installer l’application (ou ajoutez-la à l’écran d’accueil depuis le menu de Chrome ; sur iPhone : Partager puis « Sur l’écran d’accueil »). Vous pourrez la lancer sans Wi-Fi ni données mobiles : la saisie, l’appareil photo, la galerie, les annotations, la sauvegarde locale et le PDF restent disponibles.

L’application vérifie automatiquement les mises à jour dès que le réseau revient. Vous pouvez aussi utiliser le bouton 🔄 Vérifier la mise à jour. Si une nouvelle version est disponible, un message propose de recharger la page.

Hors ligne, un bandeau signale que l’envoi vers la base partagée Supabase n’est pas possible. Les données restent enregistrées sur l’appareil.

10. Aide-mémoire (points à contrôler)

  • Consulter : appuyez sur 📋 Aide-mémoire. La liste regroupe les rubriques (circulation, EPI, machines, électricité, travail en hauteur). Elle fonctionne aussi hors ligne ; ← Retour ferme la page.
  • Modifier : appuyez sur ✏️ Modifier (en haut à droite).
    • Touchez un titre ou un point pour changer son texte.
    • ↑ ↓ changent l’ordre, ✕ supprime un point ou une rubrique, ＋ Ajouter un point et ＋ Rubrique en ajoutent.
    • Puces : Onoré (étoile + o), étoile dorée, coche, rond, case à cocher ou aucune.
    • Disposition : cartes, liste compacte, ou deux colonnes (sur écran large ou tablette en paysage).
    • Taille du texte : petit, moyen ou grand.
  • Enregistrer : appuyez sur 💾 Enregistrer, puis saisissez le mot de passe. Avec un mot de passe incorrect, rien n’est enregistré et vous pouvez continuer à modifier.
  • Publication : après le mot de passe, le texte est enregistré sur l’appareil puis publié sur GitHub. Il est visible par tous les utilisateurs d’ici environ une minute, et la version de l’application avance automatiquement. Si l’envoi échoue (pas de réseau, jeton refusé), un bandeau indique que la version reste sur l’appareil : utilisez ↻ Envoyer vers GitHub pour réessayer.
  • ⚙️ GitHub (mode édition) : à renseigner une seule fois sur l’appareil de l’administrateur (propriétaire, dépôt, branche, fichier et jeton d’accès). Le jeton reste sur cet appareil.
  • Annuler abandonne les modifications en cours ; Réinitialiser revient à la version publiée ; 📤 Exporter télécharge le fichier memo.json (solution de secours).
  • À chaque ouverture, l’aide-mémoire est relu depuis GitHub. Hors ligne, la dernière version connue est affichée.

11. Enregistrement du fichier Excel sur l’intranet

Appuyez sur 🌐 Enregistrement sur l’intranet pour choisir où sont enregistrés les fichiers 📊 Excel et 🗄️ Excel base complète.

  • Désactivé : le fichier est seulement téléchargé sur l’appareil.
  • Dossier réseau (ordinateur ou tablette Windows avec Chrome ou Edge) : saisissez le chemin réseau du dossier (par exemple \\serveur\partage\Visites), puis appuyez sur 📁 Choisir le dossier…. Le chemin est copié : dans la fenêtre Windows, collez-le dans la barre d’adresse (Ctrl+V), validez avec Entrée, puis « Sélectionner le dossier ». L’application vérifie que le nom du dossier correspond à la fin du chemin saisi. Le navigateur peut redemander l’autorisation d’écriture à chaque nouvelle session. Ce mode n’existe pas sur téléphone, iPhone, Firefox ou Safari.
  • Mémoriser : appuyez sur Enregistrer, puis saisissez le mot de passe. Sans mot de passe correct, le chemin et les réglages ne sont pas modifiés. Ils restent sur l’appareil : à refaire une fois sur chaque tablette.
  • Serveur intranet (aussi sur téléphone) : indiquez l’adresse https du serveur, la méthode (PUT ou POST) et, si besoin, un identifiant et un mot de passe. L’appareil doit être sur le Wi-Fi de l’entreprise ou en VPN, et le serveur doit autoriser l’application (à demander au service informatique).
  • Tester l’envoi dépose un petit fichier test-visite-securite.txt pour vérifier le réglage.
  • La case Télécharger aussi une copie sur cet appareil garde une copie locale. Si l’enregistrement sur l’intranet échoue, le fichier est toujours téléchargé et un message l’indique.
  • Les réglages (dont l’identifiant et le mot de passe éventuels) sont mémorisés uniquement sur cet appareil.

À savoir

Pour ouvrir directement la caméra, la page doit être hébergée en HTTPS (GitHub Pages, Netlify, etc.). Un fichier HTML ouvert localement ne peut pas accéder à la caméra sur la plupart des téléphones.

Mode hors ligne : l’application démarre depuis la mémoire du téléphone. L’envoi vers la base partagée reprendra à la reconnexion.
