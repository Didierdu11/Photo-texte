RAPPORT PHOTO V3
- Numéro, titre, machine, description
- Date automatique
- Photos prises avec Android
- Compression des photos pour limiter la taille
- Commentaire par photo
- Suppression individuelle
- Sauvegarde locale
- Export XLSX avec les photos réellement intégrées dans le classeur via ExcelJS
- Partage Android du fichier Excel

Installation : héberger ces fichiers sur un site HTTPS, ouvrir dans Chrome Android puis choisir "Ajouter à l'écran d'accueil".
La bibliothèque ExcelJS est chargée depuis jsDelivr ; une connexion Internet est donc nécessaire lors de la première utilisation, sauf si elle est ensuite mise en cache.
